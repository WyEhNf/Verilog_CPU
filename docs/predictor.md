# A-02 分支预测器和 BTB

`rv32_branch_predictor` 包含 64 项 2 位双模预测表和 16 项直接映射 BTB。BHT 使用 `PC[7:2]` 索引，复位为弱跳转状态（`10`）；BTB 使用 `PC[5:2]` 索引并保存 `PC[31:6]` 标记、目标和控制流种类。

条件分支只有在 BHT 高位为 1、BTB 标记命中且 BTB 种类为条件分支时才预测跳转。BTB 未命中一律预测顺序地址，避免使用冲突项的旧目标。JAL 从机器码重排立即数并直接预测跳转，不占 BTB；JALR 必须命中种类正确的 BTB，保存目标时清零第 0 位。

所有表项只在 `feedback_valid_i` 的提交沿训练，冲刷／重定向不回滚预测器。条件分支跳转时更新 BTB 并饱和增加 BHT，不跳转时饱和减少 BHT；JALR 跳转时更新 BTB。查询同时输出 BHT/BTB 索引和当前计数器，供 ROB 保存预测元数据和定位误预测。

统计计数器同样只在提交反馈握手时增加。正确预测要求跳转状态一致；实际跳转时还要求目标一致。验证入口 `make a02` 覆盖跳转／不跳转饱和、交替状态迁移、BHT 别名冲突、BTB 标记冲突、未命中／命中、JAL、JALR 目标第 0 位清零和统计值。
