# 重命名单元（B-02）

`rv32_rename_unit` 维护推测 RAT、已提交 RRAT 和非零物理寄存器空闲位图。输入指令束
按通道顺序处理，只产生资源足够的连续前缀。组合阶段先复制 RAT 到临时工作映射；每个
写 rd 的通道通过优先选择取一个空闲物理寄存器，并在指令束工作位图中清除；后续
通道的源查询立即看到该新映射，因而
覆盖指令束内 RAW 和 WAW。

`rename_ready_i`、ROB/RS/LSQ 空闲计数或空闲位图空间任一阻塞时，不接受后续通道。x0 固定映射 P0，
对 x0 的写不消耗空闲项。时钟沿写入 RAT 并清除已分配位；提交沿更新 RRAT 并置回
旧物理寄存器对应位。恢复沿以完整 RAT、空闲位图和计数替换推测状态，
优先于普通重命名／提交。

`rat_state_o`、`rrat_state_o` 和 `free_bitmap_state_o` 是可用于恢复／验证的扁平状态。
位图初始时 P1 到 `P{PHYS_REGS-1}` 为 1，P0 恒为 0，因此无需非二幂环形指针。
`rename_new_phys_o` 与 `rename_rd_we_o` 同时驱动 PRF 的分配清除端口。

分支检查点仍只保存 RAT。恢复时先装入检查点 RAT，再重放分支自身的目的映射；
ROB 汇总严格年轻项的新物理寄存器为回收位图，后端将它与当前空闲位图取并集，
得到恢复后的空闲状态。该路径不再把空闲寄存器动态压缩成宽空闲列表总线，也不需要
在后端联合模块中复制 ROB 的物理寄存器／逻辑寄存器元数据。

验证命令：`make b02`，覆盖 `BE_WIDTH=1/2/4` 与 `PHYS_REGS=48/64/96`。
