# 保留站与发射选择（B-04）

`rv32_reservation_station` 保存一类执行端口的等待项；INT、MUL、DIV 通过参数化实例
分离。每项包含操作、PC、完整 ROB 标记、目标物理寄存器、两个源的值／标记／就绪状态和存储数据。

分配只接受连续有效前缀，RS 满时停止。CDB 唤醒在时钟沿更新，完整的有效位、槽位和代际
标记匹配后将源置为就绪，因此 N 周期收到的唤醒最早在 N+1 选择。组合选择按年龄最小、再按
槽位编号最低的确定顺序输出最多 `BE_WIDTH` 项；执行端口未就绪时，条目保持不变。

冲刷使用条目取消掩码在一个沿清除严格年轻项；被清除项不能再次发射。只有目标仍存活
且两个源均就绪的项可选择，避免 ROB 恢复后旧项重新进入执行端。

验证命令：`make b04`，覆盖 BE_WIDTH=1/2/4、RAW 唤醒、RS 满、最老项优先、背压、
冲刷和代际不匹配。
