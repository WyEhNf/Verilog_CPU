# B-05 整数 ALU、分支与地址生成单元

`rv32i_alu` 接收一个整数保留站发射包，并输出一个寄存后的执行结果。输入立即数是经过符号扩展的 32 位值。结果在 `issue_valid_i && issue_ready_o` 之后的下一周期可见，并保持稳定，直到 `exec_ready_i` 置位。

该单元实现 RV32I 算术、逻辑、比较、移位、LUI、AUIPC、条件分支、JAL 和 JALR。移位量仅使用位 4:0；JALR 将目标地址最低位清零。加载与存储操作只计算 `rs1 + immediate`，并向 LSQ 返回访存元数据和存储数据。

分支结果包含实际目标、是否跳转、下一 PC，以及预测与实际结果不符时的重定向请求。`flush_i` 会丢弃待处理结果。`live_tag_valid_i` 置位时，只有完整 ROB 标签等于 `live_tag_i` 的待处理结果才可见。
