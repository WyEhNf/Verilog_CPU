# 共享 Tier3 的 500 MHz 集成配置

最初 78b71916 准备发生在 Tier1 aea34a6f PPA 期间，该 Tier1 测量随后未通过频率门。本配置准备不额外启动综合、CPU 构建、性能或正确性测试，不确立 500 MHz 或新 Tier3 IPC／面积。

configs/tier3_shared_500_candidate.json 最初固定该阶段课程顶层全部 183 个数值参数，而非继承空覆盖映射。资源保留 FE4/BE2/INT2/CDB2、ROB32/PHYS56/RS8/LSQ16、Icache128/Dcache1024，保留寄存 DISPATCH_PIPELINE=1 及原寄存器 PRF（PRF_VALUE_SRAM=0）。历史 88e460d3 顶层与当前顶层都公开的原数值默认值比较相同；历史顶层还含后来公开为参数的硬接线设置。此文本／默认值比较不是新 CPU 测量，也不是完整源码版本等价证明。

组合启用待处理分支所有权查询、MDU 余数复用／前缀符号修正、取指所有者载荷选择、完整宽度单 generation 所有权、LSQ 保存请求／候选状态查询、分阶段／直接载荷选择、限定保存 MMIO STORE 路由／写容量就绪、窄缓存查询字及 MSHR 无所有权清除抑制。使用相同 cpu_core/rv32_backend_joint/cache 实现，参数检查器接受此组合。500 MHz 门槛编码目标 2，原课程门槛元数据保留于 configs/tier3.json。

Tier1 直接分派／空 RS 旁路和新鲜 RS 数据选择要求另一种已支持分派契约，因此此处保持禁用。PRF SRAM 原始写入／端口转发要求 SRAM PRF，也保持禁用。完成／STORE 同边沿退休旁路、译码队列变化及新鲜分配 LOAD 请求旁路在首个集成配置中同样关闭。这保持原流水线／资源配置，并将初始组合限制在已审阅、意图保持周期的改动。

既有有限样例支持独立所有权／布局论证，不证明完整 Tier3 配置。尤其 LSQ 直接载荷样例为 BE2/LSQ4，待处理所有权样例为 ROB8，而此配置为 LSQ16/ROB32。后续任何受门控 CPU 运行都保留完整生产新旧查询及所有权断言。这些通用实现保留原完整标签／generation 宽度及保护，不引入按宽度分离 CPU。

评估在当前 Tier1 验收工作后开始：一次提交源码冻结、一次原结构静态检查及一次完整官方 PPA。执行课程范围（面积 <=36000、IPC >=1.0985）、目标频率 >=500，以及用户要求相对原实测 A109 基线不回退：面积 <=35891.672317998215、IPC >=1.1152626918348099，逐项周期不大于 7572/17490/143485/153155/4739/3725。只有满足面积／频率条件的 PPA 才进入一次六项性能测试，全部指标／周期门通过后执行一次 array1 冒烟测试。被拒绝组合不能替换保留基线。此验收不完成后续 IPC1.5/1GHz／不限面积探索目标。

## 增加完成源状态查询

76bc5f42 之后，准备配置还启用 COMPLETION_SOURCE_STATE_QUERY=1，固定参数增加为当前全部 184 个数值顶层参数。COMPLETION_BYPASS 仍为 2，寄存分派、寄存器 PRF、资源大小及全部先前选择不变。将同一当前错误／大小表查询前移到直接完成仲裁之前，原身份检查、CDB 源所有权及时钟边沿保留，不使用未报告 LOAD 所有权捷径。参数检查通过。单独 BE2/ROB8 直接／分阶段有限样例及 Tier1 结构静态检查，不证明 ROB32 Tier3 等价或时序。独立冻结 Tier1 源状态 PPA 运行时，不增加 Tier3 测试／EDA，验收仍执行上述全部原门槛。准确新配置／顶层哈希及历史准备关联见 reports/Tier3_shared_500_source_state_profile_preparation_2026-10-09.json。

## 已验证 Tier1 后的集成

共享 509377c4 源码以 8968.688155 um2 / 305.854241 MHz / IPC 0.6012842155901663 通过 Tier1，六项周期不变，一次 array1 冒烟测试通过。此 Tier3 准备配置现固定全部 185 个数值参数，启用 COMPLETION_SOURCE_STATE_QUERY=2 和 LSQ_DISTRIBUTED_LOAD_FORMAT=1，保留此前流水线／资源。这些是有限 BE2 后端／LSQ 样例已覆盖、Tier1 已测的同一通用策略，不是分离宽度实现。源／查询／格式化器改动不增加周期，Tier1 结果不构成 Tier3 测量。

门槛现直接编码面积 <= 35891.672317998215、IPC >= 1.1152626918348099、Fmax >= 500，防止运行器仅凭课程最低门槛继续。原课程门槛另保留于准备记录，全部逐项周期检查仍为必要条件。Reports/Tier3_shared_load_format_profile_preparation_2026-10-09.json 记录后续仅参数修订，更早准备保留为历史。

## 不借用释放信用的分阶段捕获准备

独立 configs/tier3_shared_500_exclusive_candidate.json 固定当前全部 186 个数值参数，仅在前一配置上增加 LSQ_PHASED_ALLOC_EXCLUSIVE=1。释放信用仍禁用，分阶段／直接事件所有者启用，因此生产保护接受同一通用策略。保留 FE4/BE2、ROB32/PHYS56/RS8/LSQ16、原缓存、寄存分派及寄存器 PRF。更早已冻结的 185 参数运行保持完整。此准备不启动 Tier3 静态检查、PPA、构建、性能或冒烟测试。有限 BE2/LSQ4 样例不是完整 LSQ16 CPU 证明。Reports/Tier3_shared_exclusive_profile_preparation_2026-10-09.json 记录准确配置／顶层哈希和全部验收门。当前 Tier2 评估后，评估一次完整冻结，不从另一档位推断 500MHz 或当前源码 IPC。
