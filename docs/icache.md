# A-03 一级指令缓存

`rv32_icache` 是 1 KiB、直接映射、16 字节缓存行的指令缓存，共 64 项。索引为地址 `PC[9:4]`，标记为 `PC[31:10]`。CPU 端请求携带原始 PC 和前端代次，响应返回完整 128 位缓存行、原始 PC、缓存行地址、代次和错误位。

命中路径固定经过请求、比较、响应三个寄存阶段。请求在上升沿 N 被接受且下游不反压时，命中响应在 N+3 才可见；没有组合数据旁路。流水充满后，已命中且无冲突的请求可以每周期接受一项。响应被反压时，完整载荷保持稳定并停止前级流水。

首版只允许一个未命中请求。为防止已经接受的请求因随后发现未命中而丢失，入口在流水非空时只接受当前阵列可确认命中的请求；接受冷启动／冲突未命中后立即保留未命中资源，直到三级查找确认、MSHR 发出缓存行请求并消费回填。回填即使属于旧代次也会写入缓存，便于后续正确路径复用；只有返回取指队列的响应按 `current_epoch_i` 过滤。

主存端使用 H-03 的缓存行就绪／有效协议，事务 ID 低位携带代次。缓存行地址或 ID 不匹配会产生确定的错误响应，不写阵列。事件输出分别标记 CPU 请求、第三级查询命中／未命中、成功回填和入口停顿，供 A-06 统计模块计数。

验证入口 `make a03` 使用真实 50 周期双端口主存模型，覆盖冷启动回填、严格三周期连续命中、小端缓存行、同组冲突替换、越界错误、事件计数、完整响应载荷反压稳定、重定向后旧命中丢弃，以及旧代次未命中只回填不交付。
