# 当前候选实现与验证状态（2026-09-26）

这是项目报告草稿和证据索引，不是 Tier 3 已验收声明。用户已指定使用 `CPU-2026-Benchmark` 继续测评；pi 按要求冻结。SRAM 定价、存储端口合法化及完整存储路径时序尚未验收。

## 配置与组成

当前性能候选使用乱序执行、顺序提交，前端/后端宽度 4、整数发射宽度 4、CDB 宽度 4、ROB 32、PRF 64、RS 16、LSQ 8，取指队列和完成队列各 16。D-cache 共 1024 个 16-byte 行、2 路、索引 hash 开启，即数据容量 16 KiB；I-cache 共 64 个 16-byte 行、2 路，即 1 KiB。I/D MSHR 分别为 8/4。CheckpointImpl=1，MulImpl/ShiftImpl/PhysTagImpl=0，GenerationWidth=8，统计计数器开启。

组成包括预测/取指、译码/重命名、物理寄存器、保留站、整数执行、乘除单元、LSQ、完成网络、ROB、非阻塞 I/D cache 与内存接口。预测器为 256 项 2-bit bimodal BHT 和 64 项直接映射 BTB，含冷启动后向分支预测；不是 TAGE 或大型混合预测器。

RV32IM 的半字及 M 扩展 smoke 测试通过；按需求不支持/不要求 CSR、FENCE/FENCE.I、ECALL/EBREAK 和非自然对齐访问。退出采用 `0x80000000` 的 32-bit SW，WSTRB=0xf，比较完整 32-bit 返回值。外部内存为 256 MiB 小端统一数组、20 周期响应；I/D outstanding 分别为 16/8。统一地址空间已有验证，但两个请求队列的并发带宽是否符合严格单端口评测接口仍须确认，不能仅因共享数组就视作接口完全合规。

## 历史参数敏感度

来源为 `build/cpu2026/sens_p2_hash_d128/*_manifest.json` 和对应结果 JSON。以下是在同一历史 P2 基线上逐项改变单个参数；不能和当前 P4 不同源码、退出/内存配置拼接成最终成绩。基线 FE/BE/整数发射/CDB=2，ROB16、PRF48、RS4、LSQ8、D-cache128行、D-MSHR4、20周期内存。表中几何平均由六项 ipc 重新计算。

| 单项改变 | IPC 几何平均 |
|---|---:|
| 无（基线） | 0.704543735 |
| 仅整数发射宽度 2→1（不是全前后端单发射） | 0.604912970 |
| ROB 16→32 | 0.726138810 |
| RS 4→8 | 0.738013218 |
| PRF 48→64 | 0.704543735 |
| LSQ 8→16 | 0.712444889 |
| D-MSHR 4→8 | 0.713549491 |

历史小窗口中增加 RS 比单独增加 PRF 更有效，ROB 和内存并发也有收益。不能将联合改变得到的当前 1.09920 全归因于四发射，或把这个排序自动推广到当前更大窗口。
