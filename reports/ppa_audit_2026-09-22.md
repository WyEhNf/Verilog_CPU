# CPU PPA audit: large-configuration reference snapshots (2026-09-22)

## Verdict

These saved large-configuration snapshots do **not** satisfy any scoring stage because the 300 MHz gate is not met. The six CPU-2026 tests pass and aggregate IPC is 1.410439, but the best audited standard-cell timing variant reaches only 40.27 MHz.
These measurements predate the retired-load LSQ repair. See `evaluation_alignment_2026-09-22.md` for the newer experiments; do not combine snapshots from different RTL versions as proof of qualification.

## Area interpretation

The complete all-standard-cell reference is 286317.30 um^2, with no unpriced leaves or generic memories. The stage table uses this complete figure. Cache-storage exemption is not inferred from the main-memory exemption; a different permitted memory mapping must be assessed separately.

The 35131.78 um^2 headline is not a complete chip area. It prices ASAP7 standard cells while the flattened timing inventory still has 134 live `$mem_v2` boundaries (367632 bits) unpriced. Two cache data arrays need 10934.30 um^2 of characterized SRAM macros. Pricing the remaining 97296 bits at only one DFF per bit adds 28371.51 um^2 before address decode, read muxes, write priority, banking, replication, or routing. That produces an optimistic hybrid floor of 68327.74 um^2, not a final total.

## Timing interpretation

OpenSTA uses the unmodified ASAP7 RVT TT NLDM libraries, a 3.333 ns clock and 0.100 ns uncertainty. A balanced BUFx8 tree limits data fanout to 16 and adds 34639 buffers (6060.44 um^2). Even then the minimum period is 24.833 ns (40.27 MHz), with the critical region running from ROB recovery/redirect through backend and reservation-station selection into ALU lane 3. Because this is an actual violating standard-cell path, unmodelled memory timing cannot turn the result into a pass.

## Required corrective work

1. Insert a real registered issue stage (or otherwise split the ROB/RS-to-ALU path); buffer sizing alone improves Fmax only to about 40 MHz.
2. Consolidate cache data-array writes to one physical SRAM port and bind those arrays to the characterized ASAP7 macros.
3. Reduce the now-measured ROB/RS/LSQ/PRF control and multi-port costs; keep every internal structure accounted for.
4. Re-run Verilator CPU-2026, Yosys area, and full OpenSTA after those architectural changes.
