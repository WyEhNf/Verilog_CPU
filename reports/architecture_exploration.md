## 目标与评测纪律

使用 Yosys + ASAP7 完整计价、Verilator + CPU-2026 六项基准统计 IPC，并要求频率至少 300 MHz。面积/IPC 必须来自同一配置并同时满足 10,000/0.6、20,000/0.78 或 40,000/1.014。全部内部存储目前采用标准单元展开；外部主存不在综合顶层。不能用未计价 SRAM 黑盒面积或大配置 IPC 拼接小配置面积。

主存为统一数组，性能延迟 20 周期。测试环境的独立 I/D 请求队列及在途数是明确记录的假设，不是从规则中推导出的唯一官方接口。STA 使用 3333.333333 ps 时钟、100 ps 不确定度、1 fF 输出负载和理想连线。旧脚本曾将 ps 库中的 3.333 错当成 3.333 ns，已修正；没有布局布线和寄生提取，频率均为预布局估算。

## 已验证的探索

| 探索 | 结果与取舍 |
|---|---|
| 大窗口与大缓存 | 四发射、PHYS96、ROB64、RS16、LSQ16、D-cache 32 KiB 在 20 周期主存下 IPC 1.41044，但完整面积的历史快照约 286,317 µm²；不能作为达标方案。当前大配置未在每次后续修改后重做完整 PPA。 |
| 小窗口与小缓存 | 双发射、PHYS48、ROB16、RS4、LSQ8、D-cache 1 KiB 完整面积可进入 40,000 范围，但 IPC 仅 0.47714。联合缩参不能证明单个参数的敏感度。 |
| LSQ 退休 load 恢复 | 已退休 load 可能仍滞留在等待缓存确认的 store 后；ROB 槽复用后，单凭槽年龄会误杀它并破坏队列连续性。增加精确退休标签记录，保留已退休前缀，同时仍删除未退休错误路径 load。 |
| RS 并行选择 | 由多路串行最老选择改为 ready 条目年龄排名，保留同周期唤醒与输出契约。小配置面积、时序改善；成对比较随队列规模增长，大配置面积不能外推。 |
| LSQ 静态 hazard 与选择树 | 静态槽位检查替代年龄旋转读取；平衡树选择最老访存，每个字节选最近的旧 store。未增加流水周期，逐项基准周期保持不变。 |
| ROB 回收位图 | 串行位图去重计数改为并行目的寄存器匹配、OR 位图和平衡 popcount。保留重复编号只回收一次的语义，最差路径转移回访存。 |
| XOR 缓存索引 | 地址序列模型提示冲突收益后实现可选 XOR 索引，完整保留高地址 tag，并反算脏行写回地址。1 KiB IPC 从 0.47714 升至 0.54076，面积增加约 145 µm²；部分测试退化，默认仍关闭。2 KiB XOR IPC 为 0.62800，但其完整 PPA 尚未测量。 |
| 乱序资源单参数扫描 | 固定 2 KiB XOR，ROB16→32 带来 +5.53% IPC、RS4→8 带来 +3.94%；PHYS48→64 为零，LSQ8→16 为 +0.085%，D-MSHR4→8 为 +0.825%。ISSUE2→1 退化至 IPC 0.5491，不可直接作为满足 IPC 的省面积方案。 |
| ROB/RS 交互验证 | ROB32+RS8、PHYS48 的 IPC 为 0.71703，比原基线高 14.18%；单独增容会把压力转向另一侧。扩大窗口后 PHYS64 仅再改善 0.14% 至 0.71803。九组共 54 次基准通过，完整面积/时序尚未测量，未作为达标配置。 |

## 验证和证据层级

定向模块测试检查恢复、标签代际、转发、反压等契约；随机差分对照独立串行参考检查选择、位图与计数；整机六项检查架构结果、退休数和 LSQ 连续性。周期等价的组合重写均核对双发射小配置和四发射大配置的逐项周期。

缓存访问序列模型只用于筛选方案，不包含预取、MSHR、实际回填延迟和请求重排，不能当作 RTL miss 或 IPC。XOR 上线后重新跑真实 RTL，并报告变慢的测试。面积审计逐叶单元对照 Liberty，检查未映射存储和未知价格；源码指纹避免把不同版本的指标混用。

本阶段未运行 pi，未新增 LH/LHU/SH 功能。现有相关路径未删除。

## 仍需探索与完成

频率仍低于 300 MHz，IPC/面积没有同时满足任何阶段。需要进一步评估 LSQ → D-cache 通路并行化或流水切分、缓存组织与写回调度、乱序窗口利用率，以及减少内部状态/多路读取的面积成本。增加流水级必须重新验证反压、错误路径 load、已提交 store 的持久性及 IPC 代价。

整数发射通道、物理寄存器、ROB/RS/LSQ 和 D-MSHR 已完成基线附近的一轮独立扫描，并补了 ROB/RS 交互实验；完整 FE/BE 宽度及更广参数覆盖仍未完成。当前证据指向：保留两条整数发射通道，避免为几乎无收益的 PHYS/LSQ/MSHR 扩容付费；以 ROB32+RS8、PHYS48 为性能候选评估其成本，而不是盲目放大所有参数。

本轮未修改 RTL，只改进实验与诊断工具，未改变默认硬件参数。`run_cpu2026.py` 现在保存 PERF/PERF_CACHE/PERF_PRED 原始计数，并拒绝重复/畸形诊断摘要；五项解析测试通过。新扫描脚本记录完整构建参数、源文件/可执行文件/报告 SHA-256，每组从头编译、验证后才清理生成的 PCH 缓存；六项架构 PASS 和统一 20 周期内存检查不放宽。综合审计、PPA 审计、缓存序列测试另七项通过。

下一步优先处理尚未满足的硬约束：现有完整 STA 的最差路径从 LSQ 寄存器进入 D-cache 寄存器，1 KiB XOR 配置最小周期 4821.20 ps，而目标为 3333.33 ps；需要评估地址/请求通路的流水切分，并验证新增周期对 IPC、刷新和反压的影响。缓存和窗口扩容只能改善部分 IPC，不能解决这条时序路径。窗口候选的完整 PPA 也需补做；当前磁盘空间仅约 0.35 GiB，综合前需对已完成的旧中间产物做可恢复归档，不能截断或省略存储映射来节省空间。
