# 严格面积口径与当前结论

依据 `docs/final_project_requirements.md` 的最终要求：面积为 Yosys + ASAP7 7.5-track RVT TT 标准单元面积，加 FakeRAM SRAM 面积。外部测试环境提供的 256 MiB 主存不属于 CPU 内部面积。

配置：bankedpred_p4_r32p64_lsq8_ram256m，定向缓冲 v4。证据为 `build/timing/bankedpred_p4_r32p64_lsq8_ram256m_proof/area_audit.json`。

| 项目 | 面积 µm² | 状态 |

| 已计价时序标准单元 | 2,743.081200 | 已核实 |
| 已计价标准单元小计 | 26,722.501020 | 已核实，非完整 CPU 面积 |

| 尚未实现/计价的存储适配逻辑 | 未确定 | 必须随合法实现纳入综合 |
| 最终总面积 | 未确定 | INCOMPLETE，不能验收 Tier 3 |

标准单元小计已包含 1,496.957760 µm² 显式缓冲，不能再加一次。源层级面积、flatten 面积和缓冲后面积是不同阶段，不得相互累加。

139 个未计价逻辑存储边界并非 139 个可直接使用的 SRAM 宏。其中还有常量 ROM、控制数组和多端口存储，必须逐项确定物理实现：映射为标准单元者计入标准单元项；映射为 SRAM 者计入 FakeRAM 项；复制、bank、选择/仲裁、写掩码、复位和外围适配成本均不得遗漏。不得把所有逻辑位数直接乘一个统一位密度当成正式 SRAM 面积。

已有理想密度情景中的 8,042.651676 µm² SRAM / 34,765.152696 µm² 算术合计不是正式成绩，不用于验收。当前 9,277.498980 µm² 是 36,000 减已知标准单元小计的剩余预算，不是 SRAM 面积，也不是完整实现一定能够通过的证明。

## 完整计算的验收条件

1. 确定被接受的 FakeRAM 工艺、宏尺寸、端口、面积和时序模型，并记录来源与配置。
2. 对全部逻辑存储逐项进行合法物理绑定；将非 SRAM 存储和适配电路实际综合到标准单元，确保无未计价叶节点。
3. 按同一冻结 RTL/配置重新统计组合、时序、SRAM 和合计，排除重复计价及外部主存。
4. 完整频率包含 SRAM 与适配路径；目前约 305.19 MHz 仅覆盖已表征标准单元路径，不是完整 CPU 频率。

严格计算尚未完成；缺少模型时保持总面积未知，不按零面积或自行选择的理想估算补齐。
